# Oneshot Royale

A battle-royale game that runs entirely in the browser — no server, no build step, no game engine download. Plain ES modules + [Three.js](https://threejs.org) from a CDN.

Play it: [https://ericspencer00.github.io/fortnite-oneshot/](https://ericspencer00.github.io/fortnite-oneshot/)

Run locally: serve the folder with any static server (ES modules need http), e.g. `python3 -m http.server` then open `http://localhost:8000`.

## Features
- Battle bus, skydive + glider drop
- Hitscan weapons with rarity tiers, ADS zoom (sniper scope), recoil, spread, reloads
- Building: wall / floor / ramp / roof in wood / stone / metal, destructible
- Harvesting trees, rocks and cars with the pickaxe
- Chests, floor loot, shield potions, medkits, ammo
- Shrinking storm with phased circles, 23 AI opponents, kill feed, minimap, Victory Royale
